# VELOURÉ — public site (production source)

Rebrand of the Orion funnel site under the VELOURÉ shield brand. Built here (not Lovable).

**Published:** https://velourefunding.com/ — custom domain (Cloudflare Registrar + DNS, Jerron's account) on GitHub Pages from repo `jerron-ux/veloure` (branch `main`, root, `CNAME`). The old https://jerron-ux.github.io/veloure/ address redirects here.
Forms are LIVE there: they post to the Orion Platform (`app.orioncapitalfunding.com`), whose nginx CORS
allowlist now includes `https://jerron-ux.github.io` (VELOURE-CORS-01, 2026-11-08).

## Design (2026-11-08, Jerron: "full control, figure it out")
- **Surface:** Decide/Learn landing — one idea per section (hero → 01 what → 02 path finder → 03 how → 04 fit → 05 talk).
- **Posture:** *velvet & chrome* — near-black velvet surfaces with grain and a spotlight, Cormorant Garamond
  light display with the key phrase in metallic italic, Archivo small-cap labels, Cinzel wordmark, sky blue only
  as the accent. **The shield is a real 3D object** (`shield.js`, raw WebGL1): the mark's outline extruded into
  a two-band chrome bevel, glossy domed navy face with the logo's cyan sheen baked in, brushed-silver V decal,
  procedural studio environment with a slow light sweep, idle sway + mouse parallax. Falls back to the SVG mark
  with no WebGL / reduced motion; pauses offscreen.
- **Colour:** the Lovable build's palette (black / sky-blue / silver / white, from the logo) → `tokens.css`.
- **Stack:** static HTML + CSS + vanilla JS, no framework, no build, no third-party anything; no inline
  scripts/styles so a strict CSP can be added when hosting supports headers (GitHub Pages does not).
- **Business logic:** `main.js` = the Orion IIFE ported verbatim behind one `CONFIG` block (brand, legal name,
  contacts, `siteHosts`, `appOrigin`, `appFnPath`); off a listed host everything is simulated and a
  "PREVIEW — FORMS NOT LIVE" badge shows. Consent text = `veloure-web-consent-v1-2026-11-08`.

## Deploy
`git add -A && git commit -m "..." && git push` — Pages rebuilds in ~1 min. Run `tools/qa.py` before, `tools/live_check.py` after.
Custom domain later: add a `CNAME` file + DNS, then add the domain to `CONFIG.siteHosts`, the og:url/og:image
URLs in `index.html`, and the nginx CORS rule on the Orion box (see `ledgers/VELOURE-CORS-01.md` in the platform repo).
